# disha-app
# Disha 2.0: Digital Sakhi 👩‍⚕️🇮🇳

> **మీ డిజిటల్ స్నేహితురాలు** — A mobile-first, high-accessibility digital safety and welfare assistant built for rural and urban communities.

---

## 🌟 About the Project
**Disha 2.0** bridges the digital and language divide by offering an intuitive, icon-first safety companion. Whether facing an emergency or looking for government welfare schemes, users can instantly access critical support through voice commands, multi-language translation, and one-tap emergency triggers.

---

## 🚀 Key Features

* **🚨 Instant SOS / Emergency:** One-tap triggers to dial emergency services like **112**, **181**, **108**, and **100**.
* **🗣️ Multi-Language Voice Assistant:** Full support for 11 regional Indian languages (**Telugu, Hindi, Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi, Odia, and English**) using web speech synthesis and recognition.
* **📍 Geolocation & Maps Integration:** Instantly locates and opens live directions to the nearest police stations and hospitals via Google Maps.
* **🏛️ Welfare Schemes Guide:** Quick-reference grids for vital welfare initiatives (such as Maternity Support and Free Ration cards).
* **🌓 Accessibility & Theme Support:** Mobile-first responsive UI featuring a clean high-contrast design with a light/dark mode toggle.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Web Speech & Geolocation APIs)
* **Wrapper:** Python, Streamlit (`streamlit_app.py`)
* **Deployment:** Streamlit Community Cloud & GitHub
